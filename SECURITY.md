# Security policy

## Supported versions

Security fixes are applied to the latest package version and the current
`main` branch. Older prerelease and package versions are not maintained after a
fixed replacement is available.

## Reporting a vulnerability

Contact the maintainer privately through the `fyziktom` account on LinkedIn to
arrange a secure reporting channel. Do not publish exploit details,
credentials, private data, or sensitive proof in a public issue.

Include the affected package or application, version or commit, reproduction
steps, expected impact, and any safe mitigation already tested.

## Scope

Reports may cover the provider-neutral driver contracts, Qdrant adapter,
dependency-injection registration, package supply chain, sample, or sandbox.
Vulnerabilities in Qdrant, .NET, or another upstream dependency should also be
reported to that dependency's maintainers.
